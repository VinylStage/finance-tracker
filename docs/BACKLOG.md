# 백로그 — 아직 이슈가 아닌 것

> **왜 이슈가 아니라 파일인가.** 이 목록은 원래 이슈 #442 에 있었고 그 본문이 "여기가 정본이 된다"고 선언했는데, 2026-08-05 에 `COMPLETED` 로 닫혔다. 항목은 하나도 착수되지 않은 상태였다. 이슈는 닫히면 목록에서 사라지고 아무 흔적도 남기지 않는다 — 2026-08-06 문서 감사에서 발견할 때까지 열흘 가까이 아무도 몰랐다. 파일은 PR 로만 바뀌므로 지우려면 diff 가 남고 리뷰를 거친다.

## 이 문서의 규칙

- **여기 있는 항목은 아직 이슈가 아니다.** 착수할 때 개별 이슈로 떼어 내고 여기서 지운다
- 한꺼번에 이슈로 만들지 않는다. 그러면 백로그가 아니라 소음이 된다
- 항목을 지우는 PR 은 **어디로 갔는지**(이슈 번호 또는 "안 하기로 함 + 이유")를 함께 적는다
- 우선순위를 매기지 않는다. 순서는 마일스톤이 정한다
